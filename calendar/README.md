# Google Calendar 匯入

這個資料夾提供可直接匯入 Google Calendar 的讀書計畫檔。

- 匯入檔：[google-calendar-study-plan.csv](./google-calendar-study-plan.csv)
- 主入口：[study-hub.md](https://github.com/reds1210/IpasAi/blob/main/study-hub.md)

## 匯入方式

1. 打開 Google Calendar。
2. 進入「設定」>「匯入與匯出」。
3. 匯入 `google-calendar-study-plan.csv`。
4. 每一天的事件描述都包含對應的 `daily/*.md` 連結，可直接點開。

## 日期範圍

- Day 01: 2026-04-28
- Day 20: 2026-05-17

## 事件內容

每個事件預設為「全天」事件，包含：

- 當日科目 1 題單連結
- 當日科目 2 題單連結
- study hub 入口連結
